# СЛТ Графика

Плагин AutoCAD для оформления чертежей слаботочных систем и автоматизации по ГОСТ — в духе СПДС GraphiCS, но под наши разделы (СС, СКС, ОПС, СОУЭ, СКУД, СОТ, АОВ, ВН, СПД, АСКУЭ, КИП и А).

**Версия 0.2.0.** Этап 1 — оформление по ГОСТ. Этап 2 — схемы автоматизации: приборы КИП, приводы, библиотека обозначений, перечень элементов.

## Установка

1. Закройте AutoCAD.
2. Распакуйте `SltGrafika.bundle.zip` в `%APPDATA%\Autodesk\ApplicationPlugins` — должна получиться папка `SltGrafika.bundle`.
3. Запустите AutoCAD — появится вкладка **«СЛТ»** на ленте. Палитра: команда `SLT_PALETTE`.

Поддерживается AutoCAD 2016–2026 (2016–2024 — сборка .NET Framework, 2025–2026 — .NET 8). Если Windows заблокировала скачанный архив: Свойства → «Разблокировать» до распаковки.

## Как это устроено

Каждый объект — «умный»: он хранит свои параметры и перерисовывается при правке.

- **Двойной щелчок** или правая кнопка → «Свойства СЛТ…» — окно свойств с русскими полями и подсказками по ГОСТ.
- **Ручки**: у выноски — излом и концы выносок, у отметки — остриё и конец полки (тянете влево/вниз — полка переворачивается), у оси — оба конца.
- **Масштаб оформления** (`SLT_SCALE`, ряд ГОСТ 2.302): текст 2,5 мм на листе остаётся 2,5 мм при любом масштабе модели. На листах (Layout) объекты всегда 1:1.
- Копирование, зеркало, перенос работают как с обычным объектом. Каждая копия получает свои параметры.
- **Без плагина** чертёж открывается нормально: объекты — обычные блоки с линиями и текстом, у смежников всё видно и печатается.
- Текстовый стиль `СЛТ_ГОСТ` (шрифт ISOCPEUR из поставки AutoCAD) создаётся автоматически.

## Команды

| Команда | Что делает |
|---|---|
| `SLT_LEADER` | Выноска: точка на элементе → излом полки → текст. Дальше можно указать ещё точки — несколько выносок от одной полки. Окончание: точка (внутри контура), стрелка (на контур), без знака (на линию) — ГОСТ 21.101. |
| `SLT_POS` | Позиционная выноска: номер берётся следующим за наибольшим в чертеже. |
| `SLT_LEVELBASE` | Базовая отметка: точка с известной отметкой (обычно ±0,000). |
| `SLT_LEVEL` | Отметка уровня на разрезе/схеме. Ассоциативная — значение считается по высоте от базовой и меняется при переносе. Можно ставить серией. |
| `SLT_LEVELPLAN` | Отметка на плане — в рамке. |
| `SLT_AXIS` | Координационная ось: марка (следующая подставляется сама, буквы Ё, З, Й, О, Х, Ц, Ч, Щ, Ъ, Ы, Ь пропускаются), начало, конец с кружком. |
| `SLT_AXES` | Массив осей по шагам `6000*4, 3000` с размерными цепочками. |
| `SLT_FORMAT` | Формат А4–А0, кратные, рамка 20/5/5/5, основная надпись форма 3 (первый лист) или форма 6 (следующие), дополнительные графы. Поля штампа копируются с предыдущего листа. |
| `SLT_SHEETS` | Автонумерация листов: на листах — по порядку вкладок, в модели — рядами сверху вниз, в ряду слева направо. «Листов» — только в форме 3. Листы со снятой галкой «Автонумерация» не трогаются. |
| `SLT_SCALE` | Масштаб оформления модели и, по желанию, применение к уже начерченному. |
| `SLT_EDIT` | Окно свойств выбранного объекта. |
| `SLT_KIP` | Прибор КИП (ГОСТ 21.208): по месту — окружность, на щите — с чертой, цифровой блок — квадрат, ПАЗ — ромб. Длинный код («DPS12») — вытянутая окружность. Центр → точка отбора на линии (с точкой) → конец ссылки на графу таблицы с номером. Enter — без линии. Следующий прибор — позиция и номер ссылки +1. В окне свойств — расшифровка кода по табл. 2 ГОСТ. |
| `SLT_IM` | Исполнительный механизм: окружность «M», линия к заслонке/клапану, позиция Y1, Y2… над ней, ссылка на графу. |
| `SLT_SYM` | Окно библиотеки: дерево, поиск, просмотр; позиция (ЦН1, ШУ1…) и наименование для перечня. Вставка серией с поворотом. |
| `SLT_LIST` | Перечень «Поз. обозначение — Наименование — Кол-во» по приборам и символам того листа (рамки формата), где стоит таблица; без рамки — по всему пространству. Одинаковые наименования — одной строкой: Y1–Y3 (подряд) или TE1, TE3, TE7. |
| `SLT_LISTUPDATE` | Пересобрать все перечни после правок. |
| `SLT_LIBRARY` | Своя библиотека (`%APPDATA%\SltGrafika\library.txt`): открыть в Блокноте или перезагрузить. Символ с тем же id заменяет встроенный во всех чертежах. |
| `SLT_REBUILD` | Перестроить все объекты чертежа (после смены шрифта и т. п.). |

## Библиотека обозначений

Текстовый файл, мм листа, начало координат — точка вставки:

```
[Вентиляция / Оборудование]          раздел дерева
= vent.damper | Клапан воздушный | Y  id | наименование | префикс позиции
C 0 0 1.5                            окружность x y r   (t в конце — толстая линия)
L -2.2 -2.2 2.2 2.2                  отрезок x1 y1 x2 y2
P -6 0 0 6 6 0 0 -6 c t              полилиния (c — замкнутая)
A 0 0 5 100 60                       дуга x y r угол1 угол2 (град., против часовой)
F 0 0 3 2 3 -2                       заливка
D 0 0 0.6                            залитая точка
T 0 0 2.5 cm "{pos}"                 текст: lb cb rb lm cm rm lt ct rt; {pos} — позиция
```

Встроенные обозначения вентиляции, арматуры и КИП сделаны по схемам автоматизации проекта СУДИО. СКС, ОПС/СОУЭ, СКУД/СОТ и АСКУЭ даны в типовом виде: замените их на обозначения своей организации в своей библиотеке.

## Сборка

Нужен .NET SDK 8 (сборка работает и в Linux).

```
./pack.sh            # проверки ядра + сборка + dist/SltGrafika.bundle.zip
dotnet run --project tools/Preview -- out   # SVG-превью объектов для сверки с ГОСТ
```

## Структура

- `src/Slt.Core` — геометрия объектов без AutoCAD (netstandard2.0/net46): выноски, отметки, оси, форматы со штампом, нумерация.
- `src/Slt.Acad` — AutoCAD: хранение параметров в XData, живая отрисовка (DrawableOverrule), ручки (GripOverrule), команды, окна свойств, лента и палитра.
- `tests/Slt.Tests` — проверки ядра, `tools/Preview` — SVG-превью.
